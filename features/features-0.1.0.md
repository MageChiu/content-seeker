# Features 0.1.0

## Current Scope
- 客户端本地搜索作为基础能力，支持 `YouTube`、`Bilibili`、`iTunes`、`Jamendo`
- 远程搜索作为增强能力保留，可按策略选择本地优先、远程优先、仅本地、仅远程
- 统一结果模型覆盖视频、音乐、播客等媒体类型
- 统一播放策略支持原生流、网页内嵌、浏览器兜底
- 搜索结果按来源正式度、可播放性、信息完整度和媒体相关性排序

## Local LLM
- 支持本地 LLM 查询改写
- 支持本地 LLM 结果重排
- 支持本地 LLM 结果摘要生成
- 支持配置 `OpenAI`、`DeepSeek`、`Ollama` 和自定义兼容接口
- 支持配置 `Base URL`、`Model`、`Key / Token`
- 调试模式下输出本地 LLM 关键调用日志

## UI Updates
- 内容源凭证输入框内聚到各自来源模块卡片中
- 搜索结果页展示本次是否经过本地 LLM 优化的轻提示
- 设置页保留搜索策略、内容源、本地 LLM 配置
