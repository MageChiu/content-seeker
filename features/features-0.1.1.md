# Features 0.1.1

## Goal
- 将 `0.1.1` 作为 `0.1.0` 之后的下一个明确迭代版本
- 让下一步开发、验收和任务拆分都围绕单一小版本展开

## Planned Scope
- 引入更多客户端直连搜索源，优先补足音频、播客和长尾内容
- 增加来源筛选、排序切换和结果状态展示优化
- 优化本地搜索失败时的单源降级和错误提示
- 继续强化本地 LLM 的搜索参与度，但保持客户端本地搜索为基础能力

## Candidate Tasks
- 评估并接入下一批客户端搜索源
- 细化结果排序规则和可视化筛选入口
- 增加本地 LLM 重排开关、缓存和失败回退策略
- 补充针对典型搜索场景的验证用例

## Versioning Rule
- `0.1.x` 表示当前小版本迭代序列
- 当前已交付版本是 `0.1.0`
- 下一步开发版本是 `0.1.1`
- 后续继续按 `0.1.2`、`0.1.3` 递增
